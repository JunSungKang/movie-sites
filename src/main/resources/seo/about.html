내 저장소에서 시작하는 영상 공간

MovieSites는 외부 저장소의 영상을 제공하는 오픈소스 플랫폼입니다. 영상을 원래 위치에 보관하면서 하나의 애플리케이션으로 탐색하고 재생합니다. 다양한 화면 테마와 표준 HTML 영상 플레이어를 사용합니다.

이 페이지에는 서비스 소개만 담고, 영상 화면과 목록은 검색 제외로 설정합니다.

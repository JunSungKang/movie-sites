# MovieSites 미궁 포털 적용 설계

선택 방법론은 기존 SDD를 유지한다. 사용자의 2026-11-07 선택 메시지 `폴더 데크 우주 시안 3번 · 미궁 포털`과 공개 시안의 해시를 `spec-liminal.json`에 기록했다. 기존 v4 명세는 동결하고 화면 요구사항 R05만 이 판본으로 대체한다.

## 적용 범위와 완료 기준

- 검보라·흑요석 배경, 절제한 별빛, 샴페인색 강조와 겹친 문틀을 적용한다.
- 폴더 탭과 여러 겹의 문틀을 가진 카드를 데스크톱에서는 3열로, 모바일에서는 좌우로 엇갈리게 배치한다. 파일 목록은 같은 분위기의 갤러리로 표시한다.
- 브레드크럼, 상위 폴더, 새로고침, 페이지 이동, 로딩·빈 폴더·오류 상태, 표준 HTML 영상 재생을 제공한다.
- 실제 폴더명과 파일 메타데이터를 사용한다. 폴더의 추상적인 포털 장식은 CSS로 표시하며, 표지 생성을 위한 하위 폴더 조회나 가짜 사진은 추가하지 않는다.
- 화면 폭 320·375px 및 PC에서 잘림 없이 탐색과 재생을 검증한다. 한 번에 표시하는 DOM과 요청은 기존 페이지 및 두 작업자 제한을 따른다.

## 실행 계획

1. 정적 HTML/CSS/JS를 교체하고 기존 API·캐시·재생 흐름에 연결한다.
2. Maven/Node 검사, 실제 폴더 이동과 캐시 재방문, 모바일·PC 시각 검수 및 재생 검증을 수행한다.
3. GitHub의 사람 커밋·push·PR, App의 현재 head 승인, 사람 merge와 정확한 head 브랜치 정리를 완료한다.
4. 기존 Docker 실행 설정을 보존해 새 이미지를 서비스 포트에 적용하고 HTTP 상태 및 파일 해시를 확인한다.

허용 경로는 프로젝트 내부의 정적 리소스, 이 판본의 설계·명세·검증 문서, README다. Java, 기존 v4 문서, 원본 영상, GitHub 보호 규칙은 변경하지 않는다. 외부 미디어와 생성 데이터는 기존 mount를 유지한다. 배포 실패 시 이전 이미지로 복구하며 실제 미검사 환경은 검증 문서에 남긴다.

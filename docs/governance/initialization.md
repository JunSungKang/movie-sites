# 기여와 저장소 운영

기능 변경은 현재 명세와 수용 기준을 확인한 뒤 기능 브랜치에서 진행한다. 원본 영상·표지·생성 데이터·비밀값은 커밋하지 않는다. 문서는 특정 운영자의 콘텐츠나 배포 주소에 의존하지 않는 범용 안내로 작성한다. 테마의 고유 문구와 장식은 해당 테마 디렉터리에 둔다.

현재 저장소는 사람 계정의 커밋·push·PR·담당자 지정과 GitHub App의 현재 head formal review를 분리한다. `quality`와 `app-review` 검사를 통과하고 현재 head가 승인된 PR만 병합한다. 새 push는 이전 검토를 무효화한다. 병합 후 검증된 head 브랜치의 원격·로컬·추적 참조를 정리한다. 구체적인 계정·보호 정책은 `.github/`의 저장소 설정에 따른다.

초기 저장소의 거버넌스 준비와 일상 기능 개발은 별도 단계다. 제품 변경을 이유로 보호 규칙을 낮추거나 인증 정보를 저장하지 않는다. 기여자는 AGPL-3.0-only와 서드파티 고지를 확인하고 변경에 맞는 검사 결과를 PR에 남긴다.

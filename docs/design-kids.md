# MovieSites 영상 놀이터

기존 SDD의 v6-kids 변경 명세다. 사용자는 2026-11-07 기존 레이아웃을 유지하면서 영유아에게 어울리는 디자인, 캐릭터 폴더 이미지와 샘플 제거를 요청했다. 이전 명세는 동결한다.

하늘색·분홍색·노란색, 둥근 폴더 카드, 직접 그린 SVG 구름·별·하트 장식을 사용한다. 데스크톱 3열·모바일 교차 폴더 배치, 영상 갤러리, 브레드크럼, 상위 이동, 새로고침, 페이지 이동과 표준 플레이어를 유지한다. 장식은 정적이며 외부 폰트나 라이브러리를 추가하지 않는다.

대표 이미지는 현재 로컬 영상의 장면을 추출해 각 폴더에 `.folder.jpg`로 둔다. 사용자 캐릭터 장면은 Git/JAR/Docker 이미지에 포함하지 않는다. 실제 보유한 뽀로로·띠띠뽀·베베핀을 표시하고, 티니핑을 떠올리는 별·하트·요정색 분위기를 장식에 반영한다. 새 영상 다운로드는 범위에 없다.

`GET /api/media/folder-cover?path=...`는 요청한 폴더의 고정 이름 `.folder.jpg`만 연다. Storage의 상대경로·SecureDirectoryStream·NOFOLLOW 경계와 기존 media 요청 동시 제한을 사용한다. JPEG 응답을 512 KiB, 한 변 1280 이하, 총 921600 픽셀 이하로 제한한다. 이미지 메타데이터는 메모리 스트림으로 검사하며 디스크 임시 캐시를 만들지 않는다. 하위 폴더 열거·영상 분석을 하지 않는다. 표지는 lazy/async로 로딩하고 없으면 기본 그림을 유지한다.

작업은 미디어 표지 준비와 샘플 3개를 미디어 밖의 무시된 복구 폴더로 이동, 화면/API/제한 테스트 구현, Maven·Node·JAR·Docker 검사, 모바일 320·375px 및 PC 검수, 공개 서비스 확인 순서로 진행한다. 나머지 30편의 경로·inode·크기·mtime을 보존한다. 허용 경로는 계약의 소스·테스트·새 설계/명세/검증 문서·README다. 배포 시 기존 mount와 리소스 제한을 유지하고 이전 이미지로 복구할 수 있게 보존한다. GitHub 사람 커밋·push·PR, App 현재 head 검토, 사람 병합과 branch 정리를 완료한다.

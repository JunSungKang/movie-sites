# 쉬운 화면 이동 검증 — 2026-11-08

대상은 v7-navigation이다. 사용자는 기존 분류를 유지하고 실제 길이 설명을 표시하도록 선택했다. 기존 단편은 89.536145~302.254150초, 중편은 660.120091~678.394195초이므로 현재 자료를 `단편 (약1~5분)`, `중편 (약11분)`으로 안내한다. 엄격한 길이 기준이나 자동 재분류를 뜻하지 않는다.

## 자동 검사 (C01)

- Maven verify 성공: 기존 JUnit 23개 통과. Dockerfile의 Maven verify도 성공했다.
- Node 캐시/페이지 이력 테스트 5개, JS 구문, 정적 내용 해시, Git 제외 및 JAR 영상 미포함 검사 통과. 낮은 위험의 표현 변경이므로 구현을 그대로 반복하는 새 단위 테스트를 추가하지 않고 실제 조작으로 검증했다.
- HTML ID가 고유하고 JS의 UI 참조가 모두 존재한다. HTML/JS에 `상위 폴더` 표현과 breadcrumb 구조가 없다. CSS의 이전 경로 나열 선택자도 제거했다.

## 화면·이동·재생 (C02)

- CSS 폭 320·375px 모바일과 1265px PC에서 가로 넘침이 없다. 모바일 이동 버튼은 높이 46px이고 목적지와 현재 선택이 읽힌다.
- 캐릭터 화면에는 `처음으로`만 표시되고, 선택 안쪽에는 `처음으로`와 `뽀로로 돌아가기`처럼 목적지가 적힌 버튼이 표시된다. 처음 화면에서는 불필요한 이동 줄을 숨긴다. 현재 친구는 작은 문맥 제목, 선택한 길이는 큰 제목으로 보여준다.
- 직접 `띠띠뽀` 주소로 진입해 처음으로 이동하고 브라우저 뒤로가기로 복귀했다. 단편 진입, 목적지 버튼 복귀, 브라우저 뒤로가기로 단편 재진입을 확인했다. 원래 경로 `띠띠뽀/단편`을 그대로 사용한다.
- 뽀로로 선택 카드 2개에 길이 설명이 표시된다. 중편에 진입하고 해당 주소를 직접 다시 불러와도 제목 `중편 (약11분)`, 문맥 `뽀로로 이야기`, 이름 있는 복귀 버튼과 10개 영상이 유지된다.
- native 버튼으로 `에디 구조 작전` 재생: duration=660.49161초, readyState=4, paused=false, currentTime=0.158069초, error=null. 재생 제목 위에도 경로 체인 대신 `뽀로로 이야기`를 표시한다.
- 기존 미디어 30편의 경로·inode·크기·mtime을 보존한다. 서버, API, 캐시 모듈, 표지 파일 및 파일명·분류는 변경하지 않았다.
- 최종 이미지를 기존 공개 포트 18081에 적용했다. HTTP health와 HTML/CSS/JS 응답이 현재 소스와 일치한다. 원본 read-only mount, 생성 데이터 mount, 사용자 501:20, read-only rootfs, 2 GiB/2 CPU/PID 128 및 unless-stopped를 유지한다. 이전 컨테이너 `moviesites-before-navigation`을 복구용으로 보존한다.

## 범위와 한계

이번 표현 변경은 사용 가능한 내장 브라우저에서 확인했다. 별도 Edge·Safari 앱, 실제 NAS 장애와 지속 부하를 새로 실행하지 않았다. 공개 IP는 이 호스트와 브라우저로 관찰하며 외부망 독립 측정을 반복하지 않았다. 길이 안내는 현재 보관 자료를 기준으로 한 표시 문구이며 하위 경로를 검색해 계산하지 않는다.

# 테마

[English](../themes.md) · [문서 목록](../../README.ko.md#문서)

모든 테마는 같은 탐색·재생 기능을 사용합니다. 나이대는 선택적인 시각 스타일 분류이며 사용을 제한하거나 나이를 수집하지 않습니다. 기존 장난감 폴더 데크인 `child-toy`가 기본입니다.

## 선택

`MOVIESITES_THEME=20s-soft-minimal`처럼 시작 전에 설정하고 프로세스·컨테이너를 재시작합니다. 대소문자를 구분하며 미등록 값은 시작을 거부합니다. 기존 테마 선택에는 재빌드가 필요하지 않습니다.

`/themes/preview.html`은 카탈로그와 `/?preview-theme=<등록-ID>` 실제 화면 링크를 제공합니다. 미리 보기는 탭 안에서만 적용하고 서버 설정은 바꾸지 않습니다. 잘못된 ID는 설정 테마로 대체합니다.

## 구조

`src/main/resources/static/themes/` 아래에 `catalog.json`, `runtime.js`, 미리 보기, `_shared/base.css`와 테마 폴더를 둡니다. 각 폴더는 `theme.json`, `theme.css`, `assets/hero.svg`, `assets/preview.svg`로 구성합니다. 영어 가이드에 전체 트리가 있습니다.

## 테마 추가

1. 기존 그룹 아래 새 폴더 또는 지원 형식의 안전한 독립 폴더를 만듭니다. 고유한 소문자·하이픈 ID와 상대 디렉토리를 카탈로그에 등록합니다.
2. 기존 매니페스트를 따라 필수 문구·정확한 로컬 hero 경로·6자리 색상을 작성합니다. 문구는 일반 텍스트로 표시합니다.
3. 적절한 상대 경로의 공통 기반 CSS와 개별 `theme.css`를 사용합니다. 구성·색상·밀도·모양·서체를 설계하되 이동 의미·표준 플레이어 동작을 유지합니다.
4. 독립 SVG `hero.svg`·`preview.svg`를 만듭니다. 미리 보기는 배치 도식이며 원본 또는 적절한 라이선스 자원만 사용합니다. 개인 영상 프레임·원격 스크립트·외부 폰트 서비스를 넣지 않습니다.
5. 기존 19개 공개 ID 호환성을 유지합니다. 최대 개수가 아니므로 새 테마를 추가할 수 있습니다. 새 그룹은 미리 보기·검사를 함께 확장할 때만 추가합니다.
6. `node scripts/validate-themes.mjs`, JAR 빌드, `bash scripts/check.sh`를 실행합니다. 모바일/데스크톱·긴 제목·포커스·움직임 축소·안내·실제 재생과 낮은 가로 화면 컨트롤을 확인합니다.

새 테마 패키징에는 재빌드가 필요합니다. 공통 탐색·캐시·대기열·재생 로직은 복제하지 않습니다. 새 자원·의존성의 라이선스를 기록하고 기본 어린이 테마가 아닌 스타일도 일반적인 영상 플랫폼 관점으로 작성합니다.

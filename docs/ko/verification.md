## 재생 시 자동 전체화면 — 2026-11-14

재생 버튼의 사용자 동작 안에서 비동기 영상 확인 전에 전체화면을 요청합니다. dialog가 아닌 내부 래퍼를 사용해 재생 컨트롤을 유지하고 대기열 영상 사이에도 전체화면을 유지합니다. 마지막 영상이 끝나면 전체화면과 팝업을 닫으며 직접 닫기는 지연된 재생·전체화면 요청을 취소하고 기존 폴더·스크롤·대기열을 보존합니다. 네이티브 WebKit은 재생 가능한 영상이 준비되면 전체화면을 시도합니다. 브라우저가 자동 전환을 거부해도 브라우저 영역을 가득 채워 재생하고 전체화면 버튼을 제공합니다. OS 전체화면을 해제하면 재진입을 강제하지 않으며 팝업을 닫을 때까지 브라우저 화면 채움은 유지합니다. 지연된 네이티브 종료 알림은 다시 연 플레이어를 축소하지 않고, 닫은 뒤 늦게 진입한 네이티브 전체화면은 다시 종료합니다. 실기기 동작은 브라우저 정책의 영향을 받습니다.

플레이어 어댑터·단위 검사는 동기 요청 시점, 권한 거부·직접 재시도, 네이티브·접두 API, 닫기 후 늦은 전체화면 완료, 연속 재생 종료, 저장 대기열과 기존 취소 동작을 확인합니다. 실제 macOS Chrome에서 플레이어 영역과 브라우저 영역의 일치, H.264 두 영상의 자동 전환 중 확대 상태 유지, 마지막 종료 후 팝업 닫힘·영상 소스 해제·저장 대기열 두 항목 보존을 확인했습니다. 320×568·812×375에서 플레이어가 화면을 채우고 닫기·다음 버튼이 영역 안에 표시됐습니다. 제어 브라우저는 사용자 입력 활성 상태에서도 네이티브 전체화면에 TypeError not granted를 반환했으므로 OS 전체화면 검증을 주장하지 않습니다. 최대 확대 대체 동작을 검증했으며 실제 iOS·Edge 기기 검사는 남아 있습니다.

## 네이티브 UTF-8 로케일 회귀 — 2026-11-09

- 장애 시 실행 이미지에는 UTF-8 로케일이 없었습니다. Java의 `file.encoding`은 UTF-8이었지만 `native.encoding`·`sun.jnu.encoding`은 `ANSI_X3.4-1968`이었습니다. 마운트 경로는 정상이었으며 API 폴더명·경로·한글 환경변수 문구에 대체 문자가 발생했습니다. 상태 확인과 영문 합성 데이터만으로는 이 배포 조건을 검출하지 못했습니다.
- 프로젝트 Dockerfile과 Compose에 `LANG`·`LC_ALL=C.UTF-8`을 명시했습니다. 격리 검증에 한글·분해형 한글·공백 경로, 정확한 한글 환경변수 문구, 원본/변환 재생·썸네일·부분 요청/토큰·FFmpeg·배타 잠금·재시작을 포함했습니다. 기존 운영 이미지도 별도 예약 루프백 포트에서 수정한 Compose 환경으로 검증을 통과했습니다.
- 공통 배포 flock 아래 해당 서비스만 재생성하고 기존 이미지·네트워크·숫자 사용자·미디어/데이터 마운트를 보존했습니다. 한글 컬렉션 3개·하위 목록·문구가 일치했고 실제 영상 썸네일/부분 재생·FFmpeg가 재시작 전후 통과했습니다. 원본 88개 파일의 해시·메타데이터가 일치했습니다. 이전 설정/이미지와 정지한 복구 컨테이너를 보존했으며 operations 파일·다른 서비스는 수정하지 않았습니다.

## Ubuntu 26.04·Compose 운영 전환 — 2026-11-09

- 고정한 공식 Temurin Ubuntu 26.04 참조로 프로젝트 전용 JDK/JRE 베이스와 앱 이미지를 빌드했습니다. 실제 엔진은 Docker Desktop Linux/arm64였습니다. 실행 환경에서 Ubuntu 26.04·Temurin 25.0.5·FFmpeg 8을 확인하고 앱 이미지에 Python·Node·javac가 없음을 확인했습니다. 운영/저장소 검사는 Python 3.14.10·Node 24.18.0을 사용했습니다. JUnit 51개·JavaScript 24개와 패키지/미디어/테마/해시/문서 검사가 통과했습니다.
- 별도 Compose 프로젝트·데이터에서 합성 H.264/AAC 원본 및 MPEG4/PCM 변환 재생·하위 탐색·JPEG·206 부분 요청·위조 토큰·경로 탈출/심볼릭 링크 거부·미디어/루트 읽기 전용·정상 종료/재시작이 통과했습니다. 실제 Chrome 변환본은 readyState 4·진행하는 재생 시각·표준 컨트롤·영상 오류 없음이었습니다.
- 실제 두 번째 writer 시험에서 Docker Desktop 바인드 마운트 간 기존 advisory FileLock만으로는 불충분함을 발견했습니다. 기존 잠금에 원자적 디렉토리 소유권을 더한 뒤 컨테이너 간 동시 시작 거부·정상 종료/재시작이 통과했습니다. 비정상 종료는 소유권 증거를 남기고 확인한 운영 복구를 요구하며 Docker 안내에 한계를 적었습니다.
- 공통 macOS 호환 배포 flock 아래 직전 이미지/컨테이너/설정·실제 마운트를 보존했습니다. 첫 운영 검증의 FFmpeg 시간 표기 오류는 자동 복구로 기존 서비스를 되살렸습니다. 명령을 수정해 격리 검증과 공용화하고 통과 후 재적용했습니다. 최종 운영은 프로젝트 `platform`·서비스 `movie-kids-web`·호스트 웹 20010 하나·UID/GID 501:20·기존 미디어 읽기 전용/데이터 쓰기 마운트입니다.
- 운영 HTTP 목록·탐색·실제 썸네일/부분 재생·FFmpeg 디코드/인코드가 통제한 재시작 전후 통과했고 healthy를 확인했습니다. 외부 원본 88개의 해시·메타데이터가 일치했습니다. 잠금 보유 중 경쟁 프로세스 획득 실패도 확인했습니다. macOS 실제 Chrome에서 대표 운영 영상의 readyState 4·진행하는 시각·영상 오류 없음을 확인했습니다. 다른 프로젝트 정지·데이터 볼륨 삭제 없이 이전 이미지/컨테이너·비공개 복구 증적을 보존했습니다.

현재 대상 환경 검증이며 Safari/Edge/모바일 실기기 전체·대형 NAS 장애/부하·독립 외부망 인증은 아닙니다. 웹 포트 변경은 브라우저 출처를 바꾸므로 기존 로컬 대기열은 이전 출처의 저장 공간에 남으며 자동 이전하거나 삭제하지 않습니다.

## 소개 페이지 테마 통일 — 2026-11-09

- 소개가 실행 테마의 CSS·로고·헤더/푸터·패키지 일러스트를 재사용합니다. 소개 배치 CSS에 별도 색상 체계·글꼴을 두지 않으며 앱 JavaScript·영상 목록 요청 없이 서버 HTML을 표시합니다.
- Gradle·다단계 Docker 빌드와 JUnit 49개·JavaScript 24개가 통과했습니다. 추가 검사는 child-toy·Midnight Stream 선택, 최신 자원 해시, 미치환 템플릿·목록 스크립트 미포함을 확인합니다. 기존 SEO/CSP/Host/304·패키지/테마·영문/한글 문서 검사도 통과했습니다.
- 두 실행 테마의 실제 Docker HTTP에서 테마별 자원 4개의 해시·immutable/304·gzip·canonical/JSON-LD/CSP·앱/API noindex가 통과했습니다. macOS 실제 Chrome에서 영상 화면과 child-toy 글꼴·배경 토큰·헤더가 일치했습니다. 소개는 390×844·320×568에서 가로 넘침 없이 표시되고 주요 링크 높이는 48픽셀이었습니다. 어두운 대체 테마도 320×568에서 일러스트 로드·가로 넘침 없음을 확인했습니다. 데스크톱·모바일 스크린샷은 로컬에 보관합니다.

현재 변경에 대한 배치·실행 검증이며 모든 테마·브라우저·기기의 포괄적인 시각 인증은 아닙니다.

## 소개 SEO·캐시 — 2026-11-09

- Gradle clean build·다단계 Docker 빌드와 JUnit 48개·JavaScript 24개가 실패·건너뜀 없이 통과했습니다. 테마·콘텐츠 해시·패키지/미디어 제외·영문/한글 문서 검사도 통과했습니다.
- 고정 만료·남은 수명·용량/항목 LRU·동시 읽기 통합·진행 작업 제한·실패 재시도·이미지 읽기 상한·버전 변경·private ETag/304를 검사합니다. 정렬 조회는 준비/완성 재사용·만료·강제 갱신을, 세션 복원은 만료 유지·루트/인스턴스 분리·저장 거부/용량 초과 대체를 확인합니다.
- 실제 Docker HTTP에서 소개 전용 canonical/Open Graph/JSON-LD/CSP·Host 헤더 독립성·robots/사이트맵 범위·앱/API/이미지/영상 noindex를 확인했습니다. 목록·이미지는 본문 없는 304, 강제 새로고침은 새 조회 ID를 반환했습니다. 정적 자원 90개가 소스와 일치하며 올바른 해시만 immutable, 불일치는 재검증했습니다. 영상 부분 요청은 206, 위조 토큰은 403이었습니다.
- 해당 로컬 측정에서 앱 모듈은 압축 전 25,024바이트·gzip 전송 7,938바이트였습니다. 이 빌드의 본문 크기이며 로딩 시간·검색 순위 보증은 아닙니다. JPEG·영상은 압축 대상에서 제외합니다.
- macOS 실제 Chrome에서 표지 표시·리로드 후 최근 목록 복원·새로고침 버튼의 최신 목록 요청·길이 구분선을 확인했습니다. 대표 영상은 readyState 4·표준 컨트롤·진행하는 재생 시각·영상 오류 없음이었고 소개 페이지에 콘솔 경고/오류가 없었습니다. 스크린샷·개인 미디어/설정 증적은 로컬에 보관합니다.

검색 제외는 이를 준수하는 크롤러 대상이며 접근 제어가 아닙니다. 검색 순위·색인 지연·Core Web Vitals 현장 데이터·비준수 크롤러·대형 NAS 지연/부하·Safari/Edge/iOS/Android 실기기 인증은 측정하지 않았습니다.

기존 대기열·영상별 썸네일·모바일 플레이어 작업을 별도 기준 커밋에 보존했습니다. 이후 빌드·패키징·공개 문서를 변경했으며 기존 실행 소스·원본 영상을 교체하지 않았습니다.

- JDK 25·표준 Gradle 9.9.0 Wrapper로 실행 가능한 JAR 빌드에 성공했습니다. 사용 전 공식 배포본과 Wrapper JAR 체크섬을 검증했으며 Spring Boot는 4.1.2를 유지합니다.

- 패키지 런타임 의존성 JAR 파일 34개가 전환 전과 일치했습니다. 단일 JAR·정적 화면 구조를 유지합니다.
- JS 검사 16개가 캐시 TTL/LRU/용량·이동 기록·대기열 저장/제한·연속 재생·취소·자동 재생 복구·모바일 플레이어 연결을 확인했습니다. 모든 브라우저 정책을 인증하는 검사는 아닙니다.
- 테마·콘텐츠 해시·Git 제외·JAR 분리가 통과했습니다. 실제 영상·표지·생성 데이터는 배포 소스 밖에 남습니다. 기존 테마 19개는 호환 기준이며 최대 개수가 아닙니다.
- Gradle 다단계 이미지 빌드 후 비루트·읽기 전용 루트 후보에서 원본/데이터 마운트를 분리하고 환경변수 테마로 시작했습니다. 상태·설정·목록·경로 거부·정적 자원 재검증 검사가 통과했습니다.

문서 29개·로컬 링크 155개에서 제목 링크·영어/한국어 대응·환경변수 예시·현재 Gradle 참조 검사가 통과했습니다. 최종 컨테이너의 정적 자원 88개가 소스와 일치하고 공개 환경변수 파일의 기본값을 불러왔습니다. 인앱 Chromium의 대표 H.264/AAC 영상은 readyState 4·진행하는 재생 시각·표준 컨트롤·영상 오류 없음으로 확인했습니다. 통합 전 최종 파일로 명령·컨테이너·서비스 검사를 반복합니다. 저장소 검사와 App 승인은 현재 head를 대상으로 하며 과거 성공이 새 head 승인을 대신하지 않습니다.

## 보존한 UI 검사 이력

기존 실행본은 macOS 인앱 Chromium에서 테마 19개 × 320×568·812×375 재생 화면, 대기열 순서/복원·연속 종료·늦은 응답 취소·표준 영상 컨트롤을 확인했습니다. 실제 H.264/AAC는 readyState 4·진행하는 재생 시각·영상 오류 없음이었습니다. 이전 상세 기록은 과거 빌드 명령을 현재 안내에 섞지 않고 Git 이력에 보존합니다.

해당 관찰은 당시 파일·환경에 대한 결과입니다. Gradle 변경으로 새 기기·브라우저 검증 범위를 주장하지 않습니다. 실제 장면·개인 경로·배포 설정·로컬 증적은 저장소에 공개하지 않습니다.

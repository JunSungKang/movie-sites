# 테스트와 호환성

[English](../verification.md) · [문서 목록](../../README.ko.md#문서)

재현 가능한 검사와 한계를 안내합니다. 운영 일지·수용량 보증·모든 브라우저/NAS/기기를 검사했다는 인증이 아닙니다. 정확한 커밋·이미지와 대상 환경에 결과를 연결하고, 변경된 파일에 이전 릴리스 결과를 그대로 적용하지 마세요.

## 저장소 검사

[개발 안내](development.md)의 도구를 준비한 뒤 실행합니다.

```bash
./gradlew clean build
bash scripts/check.sh
python3 -B scripts/check-docs.py
```

| 검사 | 확인 범위 |
|---|---|
| Gradle 빌드·테스트 | Java 컴파일, 저장소 경계, 페이지/정렬, 메타데이터, 자원 예산, HTTP/미디어 동작과 실행 패키지 |
| `scripts/check.sh` | JavaScript 문법·회귀, 테마/카탈로그, 콘텐츠 해시, PWA 캐시 경계, Git 제외와 JAR/원본 분리 |
| `scripts/check-docs.py` | 로컬 링크·제목, 영어/한국어 문서 대응, 환경변수 안내·공개 예시와 빌드 참조 |

실제 출력과 실패 내용을 확인하세요. 단위·어댑터 검사는 실제 네이티브 플레이어·설치·파일시스템·네트워크 동작을 입증하지 않습니다. 테스트 개수는 코드에 따라 달라지며 호환성 인증이 아닙니다. 공개 이미지·다운로드 명령은 해당 산출물이 실제로 존재할 때만 안내합니다.

## 격리 실행 검사

합성 영상과 별도의 생성 데이터 디렉토리를 사용합니다. smoke 검사에 운영 `/data`를 사용하거나 시험 통과를 위해 원본 컬렉션을 수정하지 마세요. [Docker 안내](docker.md) 또는 [JAR 실행](getting-started.md)에 따라 후보를 사용하지 않는 루프백 포트에서 시작합니다.

```bash
python3 -B scripts/verify-runtime.py http://127.0.0.1:8080
```

smoke 도구는 실행 중인 주소를 검사합니다. 아래 전체가 자동 검사된다고 가정하지 말고 출력과 실제 동작을 확인하세요.

- 상태·설정·현재 폴더 탐색, 한글/분해형 이름·공백·빈 폴더·미지원 파일.
- 길이순 준비·페이지·고정 만료 캐시 재사용·명시적 새로고침·잘못되거나 만료한 커서·정확한 길이 구간.
- 직접 재생 H.264/AAC MP4와 완성된 재생본 준비가 필요한 입력. 생성 결과의 FFmpeg/ffprobe 분석.
- 폴더/영상 JPEG 검증·외부 이미지·자동 썸네일, 메타데이터 제한과 선택적 주제 프로필.
- GET/HEAD·단일 byte range 정상/오류·변경 원본과 위조 토큰 거부. 서명 토큰은 일관성 검사이며 로그인이 아닙니다.
- 경로 탈출·심볼릭 링크 거부, 원본/데이터 분리, 읽기 전용 원본/컨테이너 루트, 중복 writer 거부.
- 정상 종료·재시작·작업 복구·원본 보존. 비정상 종료 복구 시험은 별도 시험 데이터 루트를 사용합니다.

시험 영상·스크린샷·상세 결과·운영 상태·개인 경로는 Git에 넣지 않습니다. 비공개 복구 증적과 공개 릴리스 노트를 구분하세요. `/api/health`는 앱의 응답 상태이며 전체 저장소나 코덱 준비 상태를 보증하지 않습니다.

Python 3.14와 빌드된 이미지를 사용하는 격리 컨테이너 시험은 다음과 같습니다.

```bash
python3 -B scripts/verify-platform.py --image moviesites:ubuntu26.04 --port 8081
```

도구는 합성 영상·별도 데이터 루트·비루트 호스트 UID/GID·고유 Compose 프로젝트를 사용하며 운영 데이터를 연결하지 않습니다. 사용하지 않는 포트를 고르세요. 생성 결과와 `--keep` 복구 정보는 로컬 운영 자료이며 공개 문서가 아닙니다.

## 브라우저와 PWA 검사

자동 회귀 검사와 함께 실제 대상 브라우저·기기에서 확인합니다.

| 영역 | 수동 확인 |
|---|---|
| 탐색 | 데스크톱/좁은 폭/낮은 가로 화면, 긴 이름, 키보드 포커스, 안내, 테마와 잘리지 않는 조작부 |
| 네이티브 재생 | 오디오가 있는 경우 소리, 재생 시간 진행, 탐색/부분 요청, 원본 비율과 지원 전체화면 조작 |
| 대기열/랜덤 재생 | 저장 목록 보존, 자연 종료 후 다음 영상, 마지막 닫힘, 늦은 준비 취소와 자동 재생 거부 대응 |
| 브라우저 저장소 | 저장 거부·용량 초과 시 현재 탭 조작 유지, 출처·원본 루트 변경 시 저장 자료 분리 |
| PWA 설치 | 브라우저 신뢰 HTTPS 또는 지원 localhost에서 기기별 설치 안내·수동 설치 |
| 연결 끊김 | service worker 활성화 후 오프라인 이동 시 제한된 연결 끊김 화면, 재연결과 재시도 |
| 비공개 응답 제외 | service worker에 목록/API 응답·개인 원본 이미지·영상·서명 스트림 URL·Range 응답이 보관되지 않음 |

PWA는 오프라인 영상이나 오프라인 목록을 제공하지 않습니다. 공개 HTTP IP 주소나 인증서 경고 우회는 운영 설치 조건을 충족하지 않습니다. 네이티브 전체화면·자동 재생·코덱 지원은 OS/브라우저 정책에 따릅니다. 페이지 안 최대 확대가 OS 전체화면 성공의 증거는 아닙니다. 지원 UI 선택은 영어·한국어이며 테마 이름이나 문서만으로 다른 언어 전체 지원을 추정하지 않습니다.

## 지원 범위와 한계

- 네이티브 서버는 Java 보안 디렉토리 스트림을 지원하는 Linux/macOS 저장소를 대상으로 합니다. Windows에서는 Linux 컨테이너와 경로 공유를 검증하세요.
- NAS/네트워크 마운트의 권한·파일명·보안 디렉토리 지원은 환경별 시험이 필요합니다. OS 호출이 앱 시간 제한·취소보다 오래 걸릴 수 있으며 페이지·메모리 제한이 초대형 폴더의 응답 시간을 보장하지 않습니다.
- 처리 용량에 의존하기 전에 장시간 동시 재생·큰 단일 폴더·느리거나 끊긴 저장소·작업 포화·디스크 고갈을 시험하세요.
- 확장자 목록이 모든 코덱을 보증하지 않으며 손상·암호화 입력은 실패할 수 있습니다. FFmpeg는 완성 호환 파일을 준비하며 영상 편집기·실시간 HLS가 아닙니다.
- 로그인 없는 읽기 전용 HTTP와 noindex는 도달 가능한 방문자의 시청을 막지 않습니다. 배포의 인증·TLS 경계를 별도로 검증하세요.
- 브라우저/기기 조합·접근성 인증·부하 목표에는 각각의 시험이 필요합니다. 이 명령만으로 Safari/iOS·Edge/Android·모든 테마·임의 장비를 인증하지 않습니다.

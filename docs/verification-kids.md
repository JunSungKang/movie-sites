# 영상 놀이터 검증 — 2026-11-07

대상 명세는 v6-kids다. 기존 검증을 동결하고 이번 화면/표지 변경을 검증했다.

## 자동 검사 (C01)

- JDK 25에서 Maven verify 성공: JUnit 23개(기존 18 + 폴더 표지 5), 실패/오류/건너뜀 없음. 최종 Dockerfile 빌드의 Maven verify도 성공했다.
- Node 캐시/페이지 이력 테스트 5개, JS 구문, 정적 파일 해시, Git 제외와 JAR 영상 미포함 검사 통과. 화면 줄바꿈을 조정한 뒤 최종 패키지와 정적 해시를 다시 확인했다.
- 새 표지 테스트는 요청한 디렉터리만 조회, 실제 JPEG 응답/MIME, 없는 표지 404, 경로 이탈 거부, 파일/부모 디렉터리 심볼릭 링크 거부, 최대 바이트·픽셀·한 변 제한, PNG/비이미지 거부를 검증한다. 유효한 외부 표지를 준비해 링크를 따라가는 결함을 탐지할 수 있게 했다.
- HTML ID 중복과 JS 참조 누락이 없으며 직접 작성한 SVG가 유효한 XML임을 확인했다.

## 화면과 재생 (C02)

- 내장 브라우저에서 실제 CSS 폭 320·375px와 PC 1280px을 확인했다. 긴 편 제목, 브레드크럼, 폴더 및 영상 목록에 가로 넘침이 없다.
- 밝은 하늘/크림 배경, 분홍·민트·하늘색의 둥근 카드, 원래의 교차 폴더 배치, 정적인 구름·별·하트 SVG와 글자 단위로 끊기지 않는 제목을 시각 검토했다.
- 실제 캐릭터 폴더 3개의 960×540 표지가 로딩됐다. 폴더별 단편/중편 표지도 실제로 읽힌다. 중편 목록에는 실제 10개 편 제목이 나타나며 lazy 영상 썸네일 8개의 로딩을 관찰했다.
- 작업에서 생성한 표지 한 개를 일시적으로 숨겨 기본 그림이 나타나고 폴더 버튼은 작동함을 확인한 뒤 즉시 복구했다. 의도한 누락 표지의 HTTP 404는 실패 검증과 구분한다.
- 최종 이미지에서 `에디 구조 작전`을 native 버튼으로 재생했다. duration=660.49161초, readyState=4, paused=false, currentTime=0.223503초, error=null. 닫기와 상위/브레드크럼 이동이 동작한다.

## 미디어와 배포 (C03)

- 샘플 3개를 활성 미디어 루트 밖 `.codex-work/kids-design/removed-samples`로 이동했다. 사용자 요청에 따라 서비스에서 제거했으며 복구 가능한 원본은 무시된 작업 영역에 보관했다.
- 기존 에피소드 30편의 경로·inode·크기·mtime이 모두 유지됐다. 공개 API 루트는 뽀로로·띠띠뽀·베베핀 3개이고 샘플 폴더는 없다.
- 현재 영상에서 고른 대표 장면을 명시적 `.folder.jpg` 7개로 두었다. 모두 512 KiB/픽셀 제한 안에 있으며 공개 표지 API 응답 바이트 해시가 준비한 이미지와 일치했다. 현재 폴더 한 개의 고정 파일만 읽으며 하위 탐색이나 영상 분석을 하지 않는다.
- 기존 Dockerfile을 BuildKit으로 빌드했다. 같은 공개 포트 18081에서 health=UP와 HTML/CSS/JS/SVG 응답의 현재 소스 일치를 확인했다.
- 원본 read-only mount, 생성 데이터 mount, 사용자 501:20, read-only rootfs, 메모리 2 GiB, CPU 2, PID 128, unless-stopped를 유지한다. 이전 컨테이너는 중지된 `moviesites-before-kids`로 복구를 위해 보존한다.
- 캐릭터 표지는 외부 사용자 미디어에만 있다. 추적하는 새 그림은 직접 작성한 SVG이며 영상/캐릭터 프레임은 Git/JAR/Docker 이미지에 포함하지 않는다. 경로/해시/작업 증거는 무시된 `.codex-work/kids-design`에 기록한다.

## 검증 한계

별도 Edge·Safari 앱, 실제 NAS 장애, 지속 동시 재생과 외부망 독립 측정은 이번 변경에서 새로 실행하지 않았다. 공개 IP는 이 호스트의 HTTP 클라이언트와 내장 브라우저로 확인한다. OS/NAS I/O 정지나 브라우저 전체 메모리에 대한 무장애 보장은 하지 않는다. 기존 원본 및 재생 보안 계약은 유지한다.
